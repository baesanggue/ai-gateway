# 30초 시연 대본 (#95, 11/17 발표 5번 장)

녹화 영상으로 넣는다(발표 중 네트워크·응답 지연 걱정이 없다). 입력은 직접 타이핑한다(자동 예시 버튼 없음).

## 녹화 전 준비

1. 켜기: `powershell -ExecutionPolicy Bypass -File scripts\start.ps1` → 프로그램 창(1200×800)이 열린다
2. **미리 한 번 보내 두기**: 시연 화면에서 아무 요청이나 한 번 보낸다. 판단 모델이 올라와 있어야 첫 요청이 느리지 않다(#84). 그다음 프로그램 창을 닫았다 다시 열거나 새로고침해서 대화를 비운다
3. 녹화 도구: Windows 캡처 도구(Win+Shift+S → 녹화) 또는 Xbox Game Bar(Win+Alt+R, 활성 창 녹화). 프로그램 창만 잡는다
4. 아래 세 문장을 메모장에 적어 두고 복사해 붙여도 된다(타이핑 시간이 줄어든다)

## 흐름 (30초)

| 시간 | 할 것 | 화면에서 보일 것 | 말할 것 (발표자 노트와 같다) |
|---|---|---|---|
| 0~3초 | 왼쪽 메뉴 **시연** | 터미널 모양 챗봇, 비어 있는 처리 과정 | "기존 챗봇의 API 주소만 바꾼 상태입니다" |
| 3~8초 | `주문한 거 배송 언제 와요?` Enter | 정해 둔 답이 바로. 처리 과정: 로컬·클라우드 판단 건너뜀, 경로 '템플릿' | "배송 문의는 LLM 없이 정해 둔 답, 비용 0" |
| 8~19초 | `김민수 고객(010-1234-5678)에게 배송 지연 사과 메일 써줘` Enter | 아래 왼쪽 **외부로 나간 텍스트**에 노란 `[고객1]`·`[전화번호1]`, 오른쪽 **받은 답변**에 김민수 | "밖으로는 [고객1]만 나가고, 받은 답변에는 김민수가 돌아옵니다" |
| 19~26초 | `이 주민번호 900101-1234567로 고객 나이 계산해줘` Enter | 빨간 안내문, 처리 과정 '클라우드 판단: 원본 필요 → 막음' | "실제 값이 필요한 요청은 밖으로 보내지 않고 안내합니다" |
| 26~30초 | 위 **비용 카드**를 가리킨다(마우스) | 기존 방식 vs 게이트웨이, 절감 % | "기존 방식보다 비용이 이만큼 줄었습니다" |

- 두 번째 요청은 답이 오기까지 몇 초 걸린다. 영상 편집(Windows 기본 앱 Clipchamp)으로 기다리는 부분을 잘라 30초에 맞춘다
- 이름·번호·주민번호는 모두 가상 값(시연용 사전, 확인 숫자가 틀린 주민번호 형식)이다

## 발표 자료에 넣기

1. 5번 장의 화면 사진을 지운다
2. **삽입 → 비디오 → 이 디바이스**로 녹화 파일을 넣고 같은 자리·크기로 맞춘다
3. **재생 → 시작: 자동**, 필요하면 **재생 → 전체 화면 재생**은 끈다(오른쪽 설명이 같이 보이게)
4. 발표 PC에서 미리 한 번 재생해 본다(코덱 문제 확인). mp4가 가장 무난하다
