## 2. 문제 — 35초

- 화면: 01·02·03을 차례로. 마지막 문장에서 아래 "대상" 줄

> 회사가 AI를 업무에 붙이면 세 가지 문제가 생깁니다.
> 첫째, 고객 이름과 전화번호가 요청에 담긴 채 그대로 외부 AI 서버로 갑니다.
> 둘째, "배송 언제 와요?" 같은 쉬운 질문까지 비싼 모델로 보내서 돈과 시간이 샙니다.
> 셋째, 이걸 막는 도구는 무거운 로컬 LLM과 복잡한 설정이 필요해서 중소기업이 쓰기 어렵습니다.
> 그래서 AI 기능을 운영하는 중소기업 개발팀과 보안 담당자를 위해 만들었습니다.

## 3. 해결 구조 — 45초

- 화면: 왼쪽에서 오른쪽으로 ①~⑤를 손으로 따라간다. "밖으로는"에서 점선 경계(이 PC 안 / 밖)를 짚는다

> 구조입니다. 기존 서비스는 API 주소만 게이트웨이로 바꿉니다.
> 요청이 들어오면 이 PC 안에서 먼저 이름, 번호, 주소를 [고객1] 같은 토큰으로 가립니다.
> 원문을 봐야 하는 기밀 판단은 이 PC의 작은 판단 모델이 합니다.
> 밖으로는 가린 문장만 나갑니다. 클라우드 판단이 그 문장을 보고, 정해 둔 답, 저렴한 모델, 고성능 모델, 막음 중 하나를 고릅니다.
> 답이 돌아오면 토큰을 이 PC에서 원래 이름과 번호로 되돌립니다.
> 원본은 밖으로 안 나가고, 쉬운 질문은 싸게, 로컬 LLM 없이 CPU만으로 돕니다.

## 4. 생성형 AI의 역할 — 35초

- 화면: 표의 "AI가 하는 일" 열을 위에서 아래로. 마지막 문장에서 맨 아래 한 줄

> 기능마다 생성형 AI가 하는 일입니다.
> 가리기에서는 이름 인식 모델이 사전에 없는 이름과 주소의 위치를 찾습니다.
> 기밀 판단은 로컬 판단 모델이, 경로를 고르는 판단은 가린 문장만 받은 판단 API가 합니다.
> 답변은 LLM이 토큰이 든 요청을 보고 씁니다.
> 값을 실제로 바꾸고 되돌리는 일은 코드가 정확하게 합니다. 판단은 판단 모델, 생성은 LLM, 가리기와 복원은 코드입니다.

## 5. 시연 — 영상 30초, 장이 열리면 자동 재생

- 화면: 넘기면 영상이 바로 돈다. 아래 시간(영상의 장면 경계, `demo-script.md`)에 맞춰 말한다. 말 합계 약 27초. 영상이 말보다 빠르면 문장 끝을 줄인다
- 영상이 안 나오면: 같은 말로 슬라이드 오른쪽 1~4를 짚는다(아래 "비상시")

> (0~2.5초) API 주소만 바꾼 챗봇입니다.
> (2.5~8초) 배송 문의는 LLM 없이 정해 둔 답이 바로, 비용 0원입니다.
> (8~19.5초) 사과 메일은 아래 왼쪽처럼 밖으로 [고객1]과 [전화번호1]만 나가고, 오른쪽 받은 답에는 김민수 고객님이 돌아옵니다.
> (19.5~25초) 주민번호로 나이 계산은 실제 값이 필요해서 막고 안내합니다.
> (25~30초) 위 카드에 비용 차이가 쌓입니다.

## 6. 결과 — 40초

- 화면: 위의 큰 숫자 넷을 왼쪽부터. 아래 표에서는 "전체 비용 절감"만 짚는다

> 테스트셋 190개와 따로 만든 데이터 622개로 쟀습니다.
> 개인정보는 99.5퍼센트 가렸고, 번호와 주소는 100퍼센트입니다.
> 실제 값이 필요한 요청은 18건 모두 막았습니다.
> 경로는 89퍼센트 맞게 골랐고, 시연 업종인 쇼핑몰은 97퍼센트입니다.
> 쉬운 요청은 비용을 95에서 100퍼센트 아낍니다. 다만 전체 절감률은 요청 구성에 달려서, 어려운 요청이 많은 이 테스트셋에서는 10퍼센트였습니다.

## 발표 날 점검 (11/17)

1. 아침: 체험판을 켜고(`scripts\start.ps1 -Beta`) 새 주소를 폼 설명에 붙여 넣는다. 휴대폰으로 9장 QR → 폼 → 체험판까지 한 번 들어가 본다
2. 발표 PC: 파일을 열고 5장을 한 번 재생해 본다(코덱). 발표자 보기를 켜서 노트가 보이는지 본다
3. 휴대폰은 방해 금지. 시간을 잴 수 있게 발표자 보기의 타이머를 0으로
4. 첫 문장을 한 번 소리 내 말해 보고 들어간다

## 연습 (11/15~16)

1. 대본을 소리 내 읽으며 장마다 시간을 잰다. 위 표보다 장마다 5초 넘게 길면 그 장의 마지막 문장부터 줄인다
2. 슬라이드를 띄우고 손으로 짚으며 두 번. 대본을 보지 않고 한 번
3. 다른 사람(또는 녹음)에게 한 번. "가린다 / 판단한다 / 되돌린다"가 들렸는지 물어본다
4. 질문 연습은 `docs/learning/qa-prep.md`의 30초 설명과 표
