# 개별 면담 기록 (2026-10-27)

M0 검증 단계. 보여준 것: Ollaya 설치, Laya 한국어 간이 테스트(#5), 판단 모델 비교(#18), 파인튜닝 계획(D11).

## 받은 의견

1. **학교에서 지원받은 API 키는 일반용**이다(교육용 계약이 아님). → OpenAI·xAI의 공개 약관이 그대로 적용된다 (`docs/llm-api-notes.md` §3).
2. **기존 데이터셋을 활용하는 것도 방법**이다. → 후보(KLUE NER, AI Hub 비식별화 데이터, Ko-UltraFeedback)를 검토했다 (`docs/dataset-review.md`).
3. **파인튜닝은 생각보다 어렵고 시간이 많이 든다.** 해도 말리지는 않지만, 가벼운 로컬 AI가 목적이라면 **성능이 받쳐 주는 데까지로 활용 범위를 줄이는 것**도 방법이다. 무거운 모델로 바꾸는 것도 방법이지만 가벼움이 차별점이라면 고려할 것.
4. **로컬 AI 테스트 기록을 GitHub에 올려 두면 좋다.** 어떤 모델을 어떤 방법으로 테스트했고, 어떤 모델이 좋고 나빴고, 적합한지 아닌지.
5. 합성 데이터셋을 만들고 확인하는 일도 시간이 오래 걸린다. 로컬 AI를 일주일 정도 돌려 봐도 된다. 어떤 방식을 택할지는 자유다.
