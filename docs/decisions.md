# 설계 결정 기록

주요 설계 결정과 그 이유를 남긴다. 새 결정은 아래에 번호를 이어서 추가한다.

## 처음부터 정한 원칙

| # | 원칙 | 이유 |
|---|---|---|
| P1 | 판단은 Laya, 생성은 LLM, 마스킹은 코드 | Laya는 판단만 하고 글 생성·위치 추출은 못 한다. 치환·복원은 정규식·사전으로 코드가 해야 정확하고 검증 가능하다. |
| P2 | 민감정보 원본은 외부·로그·DB 어디에도 남기지 않는다 | 보안 강점의 핵심 약속. 원본-가명 대응표는 요청 처리 중 메모리에만 둔다. |
| P3 | 기본 구성에 로컬 LLM을 넣지 않는다 | 로컬 LLM은 GPU·메모리가 필요해 "간편함"을 잃는다. 가벼운 판단 모델만 로컬에서 돌리고, 완전 로컬은 옵션으로 둔다. |
| P4 | OpenAI 호환 엔드포인트 제공 | 기존 서비스가 API 주소 한 줄만 바꾸면 적용되게 한다. |

## 9/29 계획 → 10/11 계획: 바뀐 점과 이유 (2026-10-11)
