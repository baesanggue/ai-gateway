# 화면 (`admin/`, #76)

시연과 관리에 쓰는 화면이다. 브라우저 탭이 아니라 **프로그램 창**(1200×800 안팎)으로 연다.

## 실행
```bash
ollaya serve                                                   # 로컬 판단 서버 (11435)
uv run uvicorn gateway.main:app --host 127.0.0.1 --port 8000   # 게이트웨이
uv run streamlit run admin/app.py                              # 화면 서버 (127.0.0.1:8501)
powershell -ExecutionPolicy Bypass -File scripts/open-app.ps1  # 프로그램 창으로 열기 (Edge/Chrome 앱 창)
```
설치·실행을 스크립트 하나로 묶는 것은 #77에서 한다.

## 구성 (11/09 사용자 의견 반영)
- **왼쪽 메뉴**(열고 닫을 수 있음): 맨 위 프로그램 이름, 기능 메뉴(시연, 파일 검사), 상태(게이트웨이 연결, 보안 수준, 업종, 사용자 사전)
- **시연**
  - 위: 숫자 카드 세 개(기존 방식, 게이트웨이 사용, 절감)
  - 왼쪽: 챗봇(기존 서비스)을 **터미널 모양**으로. 터미널 바로 아래 `›` 입력 줄에 쓰고 Enter. 화면을 열거나 보낸 뒤 커서가 입력 줄에 자동으로 간다. 시연은 직접 입력해서 한다(자동 예시 버튼 없음)
  - 오른쪽: 게이트웨이 처리 과정 다섯 단계(가리기 → 로컬 판단 → 클라우드 판단 → 경로 → 복원)마다 이름·상태(완료/건너뜀/차단)·한 줄 요약. 단계 옆 정보 아이콘을 누르면 확률 / 기준값(D24)·비용·시간 표가 **화면 위에 작은 창으로** 뜬다(화면을 밀지 않는다)
  - 아래: "외부 AI 서버로 나간 텍스트"(가명 토큰을 노란색으로) | "사용자가 받은 답변(이 PC에서 복원)"
  - 요청이 여러 개면 처리 과정 위의 목록에서 고른다
  - **화면 전체는 스크롤하지 않는다**(1200×800 기준). 터미널·처리 과정·두 칸은 높이가 정해져 있고, 내용이 길면 그 칸 안에서만 스크롤한다
- **파일 검사**: 파일을 끌어다 놓으면 개인정보 종류·개수·위치와 가명화된 텍스트(내려받기)를 보여 준다. 파일은 이 PC 밖으로 나가지 않는다(#50)
- 디자인: 예전 화면 예시(`docs/design/ui-demo.html`)의 모양(회색 메뉴, 이름표가 붙은 카드, 색으로 나눈 칸). 이모지는 쓰지 않는다
- 요청 로그·통계·벤치마크·설정 메뉴는 #78에서 더한다

## 동작
- 챗봇은 OpenAI SDK로 게이트웨이를 부른다(`base_url`만 게이트웨이). 처리 과정은 응답 헤더의 요청 ID로 요청 로그를 읽어 만든다(`admin/flow.py`). 로그에는 가명화된 문장만 있고, 원문과 받은 답변은 화면 세션에만 있다
- 메시지는 하나씩 보낸다. 앞 대화까지 보내면 "가리기"가 앞 요청의 개인정보까지 세어 시연에서 헷갈린다
- 등록한 시연용 지시문(`decision.trusted_system_prompts`, #73)이 있으면 system 메시지로 함께 보낸다
- Streamlit 설정(`.streamlit/config.toml`): **이 PC에서만 연다**(`127.0.0.1`, D20과 같은 원칙), 사용 통계를 보내지 않고, 배포 버튼을 숨긴다
- 프로그램 창(`scripts/open-app.ps1`)은 이 화면 전용 브라우저 프로필을 써서 평소 브라우저와 섞이지 않는다
