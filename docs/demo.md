# 화면 (`admin/`, #76, #78)

시연과 관리에 쓰는 화면이다. 브라우저 탭이 아니라 **프로그램 창**(1200×800 안팎)으로 연다.

## 실행
```powershell
powershell -ExecutionPolicy Bypass -File scripts\start.ps1   # Ollaya·게이트웨이·화면을 켜고 프로그램 창을 연다
powershell -ExecutionPolicy Bypass -File scripts\stop.ps1    # 끄기
```
설치는 `scripts\install.ps1`, 자세한 것은 `docs/install.md` (#77). 따로 켜려면:
```bash
ollaya serve                                                   # 로컬 판단 서버 (11435)
uv run uvicorn gateway.main:app --host 127.0.0.1 --port 8000   # 게이트웨이
uv run streamlit run admin/app.py                              # 화면 서버 (127.0.0.1:8501)
powershell -ExecutionPolicy Bypass -File scripts/open-app.ps1  # 프로그램 창으로 열기 (Edge/Chrome 앱 창)
```

## 구성 (11/09 사용자 의견 반영)
- **왼쪽 메뉴**(열고 닫을 수 있음, `admin/nav.py`): 맨 위 프로그램 이름, 기능 메뉴(**현황 / 시연 / 파일 검사 / 요청 기록 / 연동 안내 / 설정**), 상태(게이트웨이 연결, 보안 수준, 업종, 사용자 사전 — 게이트웨이가 지금 쓰는 값)
- **현황**(처음 화면): 숫자 카드 넷(처리한 요청·오늘, 비용 절감, LLM 없이 끝난 요청, 가린 개인정보), 경로별 요청과 막은 이유(가로 막대, 한 계열 한 색, 값은 옆에 글자로), 최근 요청 다섯 건. 카드 아래에 비용을 한 문장으로(#132). 비용은 LLM 비용 기준(판단 API는 190행에 $0.01, #59)
  - **첫 화면 안내**(#131, 설문에서 10명 중 5명이 처음에 할 일을 몰랐다): 아직 요청이 없으면 제목 아래에 세 단계(① 시연 메뉴 열기 ② 예시를 차례로 보내기 ③ 무엇이 가려졌는지 보기)와 "시연 시작하기"를 펼쳐 둔다. 요청이 생기거나 "닫기"를 누르면 제목 줄 오른쪽의 "처음 쓰는 방법" 작은 창으로 접는다
- **시연**
  - 위: 숫자 카드 세 개(기존 방식, 가림게이트 사용, 절감)와 그 아래 한 문장: "모든 요청을 비싼 고성능 모델로 보냈다면 약 ○원, 가림게이트로는 약 ○원이 들어 ○%를 아꼈습니다. 같은 종류의 요청 1,000건이면 약 ○원을 아낍니다."
  - 비용은 **원화**로 보인다(#132, 설문에서 달러 표시가 3.0점으로 가장 낮았다). 환율은 `config.yaml`의 `display.krw_per_usd`(기본 1,340원, 2026년 11월 기준)이고 화면에 함께 적는다. 기록(DB)·측정 문서는 달러 그대로다(`admin/money.py`)
  - 그 아래: **번호 붙은 예시 상자 넷**(#131). 누르면 문장이 입력 줄에 들어가고, Enter를 눌러 보낸다(바로 보내지 않는다: 어디에 쓰는지 익히고 고쳐서 보낼 수도 있게, 11/19 사용자 선택). 보낸 예시는 초록 "완료", 다음 할 것은 굵은 테두리. 예시 문장은 업종 프리셋의 `display.examples`에 있다(쇼핑몰: 배송 문의 / 사과 메일 / 나이 계산 / 자유롭게, 병원·학교도 같은 네 가지 경로)
  - 왼쪽: 챗봇(기존 서비스)을 **터미널 모양**으로. 터미널 바로 아래 `›` 입력 줄에 쓰고 Enter. 화면을 열거나 보낸 뒤 커서가 입력 줄에 자동으로 간다
  - 오른쪽: 게이트웨이 처리 과정 다섯 단계(가리기 → 로컬 판단 → 클라우드 판단 → 경로 → 복원)마다 이름·상태(완료/건너뜀/차단)·한 줄 요약. 단계 옆 정보 아이콘을 누르면 확률 / 기준값(D24)·비용·시간 표가 **화면 위에 작은 창으로** 뜬다(화면을 밀지 않는다)
  - 아래: "외부 AI 서버로 나간 텍스트"(가명 토큰을 노란색으로) | "사용자가 받은 답변(이 PC에서 복원)"
  - 요청이 여러 개면 처리 과정 위의 목록에서 고른다. 목록의 글은 한 줄이고, 30자가 넘으면 줄임표(…)로 끝낸다(#134, 설문에서 "…고객 나이 계"처럼 끊겨 보였다)
  - **화면 전체는 스크롤하지 않는다**(1200×800 기준). 터미널·처리 과정·두 칸은 높이가 정해져 있고, 내용이 길면 그 칸 안에서만 스크롤한다
- **파일 검사**: 파일을 끌어다 놓으면 개인정보 종류·개수·위치와 가명화된 텍스트(내려받기)를 보여 준다. 파일은 이 PC 밖으로 나가지 않는다(#50)
- **요청 기록**: 최근 200건(경로로 거르기). 줄을 고르면 오른쪽에 시각·보안 수준·가린 개인정보·경로와 이유·모델·비용·시간과 처리 과정 다섯 단계(시연과 같은 카드)
- **연동 안내**(#133, 설문에서 개발 직군 응답자가 "내 코드에서 어떻게 써야 할지 감이 안 온다"): 기존 서비스 개발자용. 연결 정보(이 PC의 게이트웨이 주소, 게이트웨이 키는 정했는지만 — 값은 보이지 않는다, 모델 이름은 아무것이나), Python·JavaScript 코드 예시(복사 단추), 응답에서 알 수 있는 것, 오류 표. 예시 코드는 `docs/integration.md`·README와 같은 함수에서 만들고, 테스트가 화면의 Python 예시를 그대로 실행해 게이트웨이를 거치는지 본다. 운영자가 아니라 개발자가 한 번 찾아 읽는 곳이라 설정 안이 아니라 메뉴로 따로 뒀다(11/21 사용자 선택)
- **설정**: 탭 넷. 저장하면 다시 시작하지 않고 다음 요청부터 적용된다(D26)
  - 보안 수준·업종: 기본/엄격/완전 로컬(#136: 완전 로컬을 고르면 로컬 AI(Ollama)가 켜져 있고 모델이 있는지 한 줄로 보인다), 업종 프리셋(FAQ 수·회사별 식별번호·이름이 아닌 낱말 수를 같이 보인다)
  - 사용자 사전: 종류별 개수만 보이고, 내용은 '내용 보기·편집'을 켜야 나온다(실제 고객 이름이 있다)
  - 등록 지시문: 운영 챗봇의 system 지시문. 시연 챗봇도 이 지시문을 쓴다. 등록 해제할 수 있다
  - 모델(보기): 판단·생성 모델과 기준값. config.yaml에서만 바꾼다(D25)
- 디자인: 예전 화면 예시(`docs/design/ui-demo.html`)의 모양(회색 메뉴, 이름표가 붙은 카드, 색으로 나눈 칸). 이모지는 쓰지 않는다
  - **읽기 쉬움 규칙**(#131, 11/19, 발표 자료 D30과 같다): 글씨는 검정·진한 회색만, 14px 이상. 칸은 회색 가는 선 대신 색 머리 띠 상자로 나눈다(파랑 기본, 초록 절감·받은 답변, 주황 외부로 나간 글, 빨강 막음). 칸 이름은 파란 이름표. 규칙은 `admin/ui.py`의 CSS 맨 위에 적어 두었다

## 동작
- 챗봇은 OpenAI SDK로 게이트웨이를 부른다(`base_url`만 게이트웨이). 처리 과정은 응답 헤더의 요청 ID로 요청 로그를 읽어 만든다(`admin/flow.py`). 로그에는 가명화된 문장만 있고, 원문과 받은 답변은 화면 세션에만 있다
- 메시지는 하나씩 보낸다. 앞 대화까지 보내면 "가리기"가 앞 요청의 개인정보까지 세어 시연에서 헷갈린다
- 등록한 시연용 지시문(`decision.trusted_system_prompts`, #73)이 있으면 system 메시지로 함께 보낸다
- Streamlit 설정(`.streamlit/config.toml`): **이 PC에서만 연다**(`127.0.0.1`, D20과 같은 원칙), 사용 통계를 보내지 않고, 배포 버튼을 숨긴다
- 프로그램 창(`scripts/open-app.ps1`)은 이 화면 전용 브라우저 프로필을 써서 평소 브라우저와 섞이지 않는다
- 설정 저장(D26): 바꾼 값은 `private/settings.override.yaml`(보안 수준·프리셋·지시문만), 사전은 사전 파일, 지시문은 `private/trusted_prompt.txt`. 저장 뒤 게이트웨이의 `POST /admin/reload`를 부르고, 게이트웨이가 받지 않으면 저장 전 파일로 되돌린다. 이 호출에는 게이트웨이가 켤 때 `private/admin.token`에 쓴 관리 토큰이 필요하다
