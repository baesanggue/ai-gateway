# 시연 화면 (`admin/app.py`, #76)

30초 시연(CLAUDE.md 7장)에 쓰는 화면이다. 왼쪽은 평범한 챗봇, 오른쪽은 게이트웨이가 그 요청에 한 일이다.

## 실행
```bash
ollaya serve                                                   # 로컬 판단 서버 (11435)
uv run uvicorn gateway.main:app --host 127.0.0.1 --port 8000   # 게이트웨이
uv run streamlit run admin/app.py                              # 시연 화면 → http://localhost:8501
```
설치 스크립트·실행 스크립트 하나로 묶는 것은 #77에서 한다.

## 화면 (11/09 사용자 의견 반영)
- **바로 보이는 것**: 위쪽 누적 비용 한 줄(기존 방식 vs 게이트웨이), 흐름 한 줄(가리기 → 로컬 판단 → 클라우드 판단 → 경로 → 복원), "밖(외부 AI)으로 나간 글", 단계별 한 줄 요약
- **한 단계 아래**: 단계를 누르면 확률 / 기준값(D24), 토큰, 비용, 시간이 펼쳐진다
- 입력창은 고정폭 글꼴(CLI 느낌), 위에 시연 시나리오 버튼 3개(배송 문의 · 사과 메일 · 주민번호 계산)

## 동작
- 챗봇은 OpenAI SDK로 게이트웨이를 부른다(`base_url`만 게이트웨이). 오른쪽 내용은 응답 헤더의 요청 ID로 요청 로그를 읽어 만든다(`admin/flow.py`). 로그에는 가명화된 문장만 있고, 원문은 화면 세션에만 있다
- 메시지는 하나씩 보낸다. 앞 대화까지 보내면 "가리기"가 앞 요청의 개인정보까지 세어 시연에서 헷갈린다
- 등록한 시연용 지시문(`decision.trusted_system_prompts`, #73)이 있으면 system 메시지로 함께 보낸다
- Streamlit 설정(`.streamlit/config.toml`): **이 PC에서만 연다**(`127.0.0.1`, D20과 같은 원칙), 사용 통계를 보내지 않고, 배포 버튼을 숨긴다
