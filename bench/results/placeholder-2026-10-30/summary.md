# 가명 토큰 유지 시험 (2026-10-30, #9)

- 실행: `uv run python bench/placeholder_check.py --out-dir bench/results/placeholder-2026-10-30`
- 대상: 테스트셋 37문장. 개인정보가 있고, 원본 값이 필요 없고, LLM으로 가며, 가명화 후 이름 토큰(`[고객N]`)이 있는 문장이다(저렴한 모델 25, 고성능 모델 12). 입력은 측정용 가명화 근사다.
- 조건: 모델 2개(`gpt-6-luna` none, `gpt-6.1-sol` low) × 지시(`llm.placeholder_instruction`) 있음·없음 = 148번 호출. 오류 0건
- 지표
  - 이름 토큰 유지: 입력의 `[고객N]`이 답변에 모두 남았는가. 복원(시연 4번)에 꼭 필요하다
  - 지어낸 토큰: 입력에 없는 대괄호 토큰이 답변에 생겼는가

- **지시가 있으면 두 모델 모두 이름 토큰을 37/37 남겼다.** 지시가 없으면 저렴한 모델은 70%를 "고객님" 같은 말로 바꿨다.
- 지시가 있어도 빠진 토큰은 전부 연락처였다(전화번호 10, 이메일 5, 주민번호 2). 메일·문자 본문에 받는 사람 자신의 연락처를 쓰지 않는 것은 자연스럽다. 빠진 토큰은 복원할 것도 없으므로 문제가 아니다.
- 지어낸 토큰: 지시가 없을 때 T064에서 두 모델이 `[후보 일정 1]` 같은 빈칸을 만들었다. 지시가 있으면 0건이었다.
- 대가: 지시문 때문에 입력 토큰이 요청마다 약 94개 늘어난다. 저렴한 모델은 $0.0000094, 고성능 모델은 $0.00019다. 고성능 모델은 지시가 있으면 출력이 짧아져서(227 → 175) 오히려 더 싸고 빨랐다.
